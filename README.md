### Projects

**[Sikkerhetsklar](https://github.com/Jakobkoding2/sikkerhetsklar)** — TypeScript, Stripe, PDF Generation
A tool to help with NIS2 compliance preparation. Generates PDF reports and handles payments via Stripe.

**[Lovdata Legal AI](https://github.com/Jakobkoding2/lovdata-legal-ai)** — Python, Hugging Face, Transformers
Semantic search over Norwegian legal texts, as an alternative to keyword search.

**[Legalize-no](https://github.com/Jakobkoding2/legalize-no)** — Python, Open Data
Tracks changes to Norwegian legislation using version control. 781+ laws indexed.

**[Norwegian CPI Nowcast](https://github.com/Jakobkoding2/norwegian-cpi-nowcast)** — Python, XGBoost
Short-term CPI forecasting using Norwegian economic data.
